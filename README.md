## ✨ Featured Projects

### 🧭 Orion · Hack the North 2026
**🏆 MLH Best Use of MongoDB**

`TypeScript` `React` `Three.js` `Node.js` `MongoDB Atlas` `OpenAI` `ElevenLabs`

An **agentic travel planner** that combines four LLM agents with deterministic routing tools to create realistic itineraries, then brings trips to life through **3D flythroughs and narrated storytelling**.

- Built four specialized LLM agents (Scout, Judger, Narrator, Director) to plan and narrate travel experiences.
- Integrated Google Maps Platform and Photorealistic 3D Tiles to visualize personalized itineraries.
- Designed MongoDB Atlas persistence for itineraries, routes, narration audio, and camera sequences.
- Implemented route scheduling, trip replay, and error monitoring with Sentry.

### 🧠 Diffusion Model Watermarking
`Python` `PyTorch` `NumPy` `Computer Vision`

Investigated the robustness of generative AI image watermarking techniques against image distortions and adversarial perturbations.

- Implemented **Tree-Ring Watermarks** and **WatermarkDM** using Fourier-domain watermark injection.
- Applied **DDIM inversion** to recover latent representations from generated images.
- Built reproducible evaluation pipelines for compression, noise, cropping, and other image transformations.
- Analyzed watermark detection performance using ROC-AUC and ablation experiments.
